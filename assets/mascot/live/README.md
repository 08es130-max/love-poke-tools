# マスコット・ミニライブ素材仕様（開発準備）

対象：ラブカポケモンツール内のランダムイベント「ライブやりまーす！」

## 動作シナリオ
1. 通常のマスコット生活中、低頻度でメンバーが「ライブやりまーす！」と宣言する。
2. 表示中の虹ヶ咲スクールアイドルから3人をランダム選出する（侑は歌唱メンバーに含めない）。
3. 3人が中央に集まったらライブ衣装に切り替わり、短いダンスを披露する。
4. 侑はその手前でペンライト（ブレード）を振って応援する。
5. 挨拶して普段の衣装・移動に戻る。イベント中もメインアプリの操作は妨げない。

## 重要条件
- ユーザーが選択していないキャラクターは勝手に追加しない。
- ライブ発生条件はアイドル3人以上＋侑が現在表示されている場合。条件不足なら発生させない。
- 音源は当面再生せず、2DモーションとCSSのスポットライトで演出する。
- 設定からランダムイベントのON/OFFを選べるようにする。
- イベントは1組まで。会話イベント・整列と重複して開始しない。
- 操作の妨げを避け、短時間の演出と低い発生頻度を初期値とする。

## 必要な画像
### ライブ衣装・ダンス
通常のちびキャラをベースに、顔・髪・頭身・色・アクセサリーを崩さず、衣装だけライブ仕様へ変更。
各メンバーの透過PNG「4コマ横一列」アニメーション。右腕上げ／左腕上げ／両腕／フィニッシュのように実際に違うポーズで、足元・頭・毛先を切らない。

- 解像度：1088×217 px
- セル：272×217 px × 横4
- 必須：RGBA透過・各セル内完結・4コマの輪郭と体格統一
- パス：`assets/mascot/live/{id}-dance.png`
- アイドルID：ayumu, kasumi, shizuku, karin, ai, kanata, setsuna, emma, rina, shioriko, mia, lanzhu

### 侑のブレード応援
- `assets/mascot/live/yu-cheer.png`
- 解像度1088×217、4コマ横一列
- 2本のブレードを上げ下げする応援モーション
- 侑の既存デザインを維持し、ペンライトと動きだけを追加

## 演出タイムライン案
- 呼びかけ：2秒
- 集合：3秒
- 衣装切替＋スポットライト：1秒
- ライブ：12秒（4コマで約200ms／コマ）
- 挨拶・解散：3秒

画像の品質確認が終わるまで、演出を本番画面へ有効化しない。
保存データのキー変更、既存キャラ画像の上書き、ライブ以外の操作ロジックの変更はしない。
